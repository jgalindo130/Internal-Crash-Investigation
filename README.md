# Internal Crash Investigation

Internal motor vehicle crash investigation form for light fleet and commercial motor vehicle (CMV) units, with a scene diagram, DOT recordable / post-accident testing determination, third-party property, litigation hold, and document attachments.

**Privacy:** this site only serves the blank form. Investigation data and attached documents are stored in each investigator's own browser and are never uploaded here. Cases are shared by saving a password-protected case file.

To update the site, replace `index.html`.
